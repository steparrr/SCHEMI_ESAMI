# Stato delle innovazioni locali

Ambito deciso dall'utente: app Mac e OpenAI già presenti, senza cloud operativo, provider grafici esterni o nuove API. Le istruzioni dei quattro allegati sono state usate come specifica tecnica, subordinate a questa scelta.

## Realizzato in questo branch

- Telemetria locale SQLite per importazione, preparazione batch, accettazione e controllo remoto osservati, rendering PDF e recupero locale; i nuovi rendering registrano pagine effettive e firma del renderer per confronti locali. Gli errori della telemetria non arrestano il lavoro.
- Home Progetti con ricerca, filtri, ordinamento, preferiti, cartella e versioni PDF già esistenti, duplicazione delle sole impostazioni e archiviazione reversibile delle materie inattive; procedura guidata in sei passi per nuove materie con validazione di identità, file, modalità e riepilogo; Control Room con overview, schemi correnti, batch, avvisi conservativi per file mancanti, heartbeat vecchio e spazio disco, statistiche misurate e riepilogo parziale dei token nelle risposte conservate. Una panoramica globale legge stati e avvisi per materia senza sommare percentuali o interrogare OpenAI. Una vista delle impostazioni espone valori effettivi e origine materia/globale; la rigenerazione con il profilo globale richiede conferma esplicita del possibile costo API. I progetti storici senza telemetria mostrano dati non disponibili.
- Materiali: stato di indicizzazione, anteprima del testo già estratto e confronto lessicale indicativo fra programma ufficiale e fonti, senza nuova OCR all'apertura.
- Report diagnostico locale con allowlist tecnica, preview completa, ZIP e nessuna trasmissione automatica.
- Recupero L1 esplicito di PDF esistenti o HTML correnti validi, con massimo due tentativi e audit locale; nessuna nuova POST.
- Medical Illustrator MVP: regole conservative per tunnel carpale, frattura e lussazione; proposte manuali e modificabili collegate a source pack e hash; bozze SVG editabili, anteprima interna, QC tecnico per entrambe le etichette dei pannelli e lista di controllo umana esplicita. Una tavola approvata può essere esportata come appendice in un PDF separato se anche la didascalia entra nella pagina, senza modificare il PDF originale o `PDF_OK`.
- Controllo visivo locale su PDF selezionati: warning per pagine quasi vuote, testo fuori bordo, riquadri opachi disegnati sopra il testo, immagini grandi con risoluzione apparente sotto 90 dpi e ultima pagina scarsa, con anteprima pagina, annotazioni dell'utente legate all'hash ed esportazione di un report tecnico locale. I warning e le annotazioni non alterano lo stato dei PDF.
- Script di installazione e aggiornamento dei sorgenti Mac; `VERIFICA-MAC.command` usa una materia temporanea e blocca le API per una prova visuale locale; guida aggiornata sui programmi necessari.

## Limiti e lavoro successivo

- Non esiste in questo branch un atlante anatomico clinicamente validato, un generatore 3D o un modello locale capace di produrre tavole fotorealistiche accurate. Le bozze vettoriali sono dichiaratamente schematiche. Mancano modelli anatomici e pipeline specializzate per le altre classi patologiche, verifica specialistica automatizzata e inserimento della figura dentro il testo dello schema.
- La Control Room mostra p90/p95 descrittivi solo con almeno 20 misure riuscite per fase e un intervallo indicativo della sola impaginazione locale quando esistono almeno 20 rendering con stessa firma e pagine simili. Non esiste ancora un'ETA affidabile dell'intera materia, una misura dell'errore delle stime a posteriori o grafici interattivi. Lo storico privo di metadati comparabili resta senza stima. Il detector usa regole fisse e conserva il significato di «stato remoto osservato»; non diagnostica uno stallo server da una lunga attesa.
- Il conteggio dei token somma i campi `usage` validi per tentativo nei nuovi job, inclusi i retry, e distingue Batch/Urgente; per i job precedenti usa l'ultimo `usage` conservato e lo mostra come modalità non attribuita. Risposte mancanti o retry storici possono non comparire; non è una misura fatturabile né una stima dei costi. Ogni nuovo record conserva modalità e modello della richiesta senza cambiare il numero di chiamate API.
- La procedura guidata usa le impostazioni di produzione già presenti. Mancano confronto semantico profondo programma-fonti, profili grafici avanzati e un editor anatomico completo. Il confronto attuale usa parole chiave e può sbagliare con sinonimi o abbreviazioni. Restano disponibili i tre gruppi di file e il controllo pilota esistenti.
- Il collegamento automatico a Codex CLI non è attivo: il report include un prompt esportabile per un uso manuale scelto dall'utente.
- Non è stata prodotta né provata una nuova app `.app`. Test automatici su Linux e compilazione Python non dimostrano la resa della GUI o l'esecuzione degli script `.command` su macOS. Lo script di verifica Mac è preparato ma non eseguito qui; prima di distribuire una build Mac servono prove visive con dati fittizi, OCR e installazione su quella macchina.
- Le due proposte cloud allegate sono escluse: a Mac spento il repository GitHub non esegue da solo la pipeline né consente la revisione da telefono.

## Verifica e rollback

Suite: `PYTHONPATH=/workspace/.schemi-deps python -m unittest discover -s tests -q`; `python -m compileall -q scripts native.py`; `git diff --check`. Nessuna chiamata API reale nei test. Le modifiche sono su branch dedicato; gli stati di esame, le risposte e i PDF esistenti non sono stati migrati. L'aggiornamento su una cartella Mac esistente conserva copia dei file sostituiti sotto `state/aggiornamenti-nativa/`.
