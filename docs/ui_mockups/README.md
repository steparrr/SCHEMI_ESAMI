# Riferimenti visivi Schemi Esami V2

Queste 35 tavole SVG editabili provengono dall'archivio `Schemi_Esami_V2_editabili_SVG_PNG.zip` fornito dall'utente il 30 ottobre 2026. Le due tavole `01d` e `08b` mostrano la finestra compatta 880 × 650 px; le altre usano 1280 × 820 px.

Sono riferimenti grafici con dati fittizi. Il comportamento effettivo è definito dal codice dell'app e non va dedotto da un'etichetta o un numero presente nei mockup. Le versioni PNG rimangono nell'archivio originale; gli SVG qui conservati si possono aprire nel browser o in un editor vettoriale.

La UI Tkinter implementa struttura, colori e gerarchia delle tavole usando i controlli nativi disponibili. Stati, costi, token, PDF e disponibilità delle azioni continuano a derivare dai dati locali e dalle verifiche reali dell'app.
